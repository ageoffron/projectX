Continue with Google or X to sign in.

Setup required

  1. Create a Firebase project and a Web app.
  2. Paste the web config into auth-config.js.
  3. Enable Google and Twitter under Authentication → Sign-in method.
  4. Authorize domain ageoffron.github.io.
  5. For X, add your X API Key and Secret in the Twitter provider settings.

Details are in the project README.
