# About Anthony Geoffron

Personal GitHub Pages site for [Anthony Geoffron](https://github.com/ageoffron).

## Live site

After GitHub Pages is enabled, the site is served at:

**https://ageoffron.github.io/projectX/**

## Enable GitHub Pages

1. Open **Settings → Pages**
2. Under **Build and deployment**, choose **GitHub Actions**
3. Merge this branch to `main` (or run the **Deploy GitHub Pages** workflow)

Alternatively, set **Deploy from a branch** to `main` / `/ (root)`.
