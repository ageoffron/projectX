Gilda Memories — Film downloads for iMovie
==========================================

Single 1080p H.264 MP4s with all 239 photos + slideshow music.

Files:
- gilda-film-1s-per-photo.mp4  (~4:00)
- gilda-film-2s-per-photo.mp4  (~8:00)
- gilda-film-3s-per-photo.mp4  (~12:00)

In iMovie:
1. Download one of the films
2. File → Import Media → select the MP4
3. Drag it onto the timeline as one clip
4. Edit further if you want (trim, titles, extra audio)

Photos are letterboxed on a black 1920×1080 canvas.
Music loops on the longer films when the track ends.
